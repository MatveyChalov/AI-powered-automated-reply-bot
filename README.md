# Виртуальный личный менеджер Матвея

Telegram Business auto-responder + личные отчёты владельцу.

## Что умеет
- Отвечает на входящие личные сообщения через Telegram Business.
- В первом ответе использует фиксированное приветствие.
- Не выдаёт себя за Матвея и не обещает решений от его имени.
- После паузы в переписке отправляет владельцу выжимку обращения.
- Сохраняет контакты и историю в SQLite.
- Команды владельца: `/start`, `/status`, `/pause`, `/resume`, `/help`.

## 1. Создайте Telegram-бота
Создайте отдельного бота через BotFather и скопируйте токен.

## 2. Получите свой Telegram ID
Узнайте свой числовой Telegram ID, например через надёжного бота-показывателя ID.
Не путайте его с username вида `@name`.

## 3. Создайте проект на Replit
Загрузите файлы проекта или импортируйте ZIP. Выберите Python.

## 4. Добавьте Secrets
В Replit откройте Tools → Secrets (название раздела может немного отличаться) и добавьте:

- `BOT_TOKEN` — токен BotFather
- `GROQ_API_KEY` — ключ Groq
- `OWNER_TELEGRAM_ID` — ваш числовой Telegram ID

Дополнительно можно задать `GROQ_MODEL`, `REPORT_DELAY_SECONDS` и `MAX_HISTORY_MESSAGES`.
Если дополнительные переменные не заданы, используются значения по умолчанию из `main.py`.

## 5. Запустите
Нажмите Run. В личном чате с ботом отправьте `/start`.

## 6. Подключите Telegram Business
В Telegram откройте:
Настройки → Telegram для бизнеса → Чат-боты → Добавить бота.
Выберите созданного бота и разрешите ему отвечать на сообщения.
Проверьте, что подключение активно и у бота есть право `can_reply`.

## Команды
- `/status` — статус подключения и количество сохранённых диалогов
- `/pause` — временно остановить автоответы (сбор отчётов остаётся включён)
- `/resume` — снова включить автоответы

## Постоянная работа
Для круглосуточной работы используйте тип публикации Replit, который держит процесс постоянно запущенным (например, Reserved VM, если он доступен в вашем тарифе).
Обычный запуск в редакторе не следует считать гарантией работы 24/7.
Проверьте стоимость выбранного типа публикации в Replit.

## Важно
- SQLite-файл `manager.sqlite3` должен находиться на постоянном диске/хранилище выбранного размещения. Если окружение удаляет локальные файлы при пересоздании, подключите постоянное хранилище или используйте внешнюю БД.
- Не публикуйте токены и ключи в коде или открытом репозитории.
- Отчёт отправляется после 45 секунд тишины в конкретном диалоге. Это значение можно изменить через `REPORT_DELAY_SECONDS`.
- Сейчас менеджер обрабатывает текст, подписи и отправленные контакты. Фото, голосовые и документы сохраняются как факт вложения, но их содержимое не анализируется.
